# OFFENSIVE SECURITY NOTES

`FIELD NOTES / TECHNICAL RESEARCH / LAB EXPERIENCES`

A personal collection of things I investigate, experiment with and learn while working through penetration-testing labs.

Some notes are about techniques, some are about tools, and some are about things that took far too long to figure out.

## What's inside?

| Section | Topics |
|---|---|
| Network Enumeration | Nmap, SMB, FTP, SNMP, service discovery |
| Linux Security | Enumeration, permissions, privilege escalation |
| Windows Security | Users, services, privileges, misconfigurations |
| Active Directory | Domain enumeration, authentication, lateral movement |
| Web Exploitation | SQLi, XSS, LFI, file uploads |
| Pivoting & Tunnelling | SSH, Chisel, Socat, internal networks |

## How I document things

I try to include:

- What the technique does.
- How to recognise the situation.
- Commands and practical examples.
- What happened when I tested it.
- Mistakes and things worth remembering.
- Possible remediation where relevant.

These are personal notes, so the content will keep evolving as I learn more.

## A few ground rules

- Experiments are performed in authorised lab environments.
- No passwords, private keys, tokens or sensitive information.
- No restricted machine solutions or exam material.
- Explanations and examples should be reproducible.
